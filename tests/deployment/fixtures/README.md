# Realtime fixtures

`request.json` and `request.npz` are the protocol-v2 golden request: plan zero,
period 25, ten identity-quaternion poses. They contain no model assets.

`noise_policy_parity.npz` is generated by the training package on CPU with
Torch 2.8.0, NumPy 2.2.6, one Torch thread and TF32 disabled. It contains two
synthetic contexts, normalization statistics, observations, full actor means
and masked samples, and three keyed epsilon summaries (first/last 64 values
and a float64 sum). It contains no trained weights. Every actor parameter is
overwritten by the closed-form expression below before evaluation; constructor
RNG state has no influence on the fixture. Both contexts include nontrivial
translation, rotation and joints.

Run with a Python environment where the training package is installed; both
`omg` and `omg_posttrain` must be importable. From the repository root, run this
exact block as `python - <<'PY'` followed by the code and a closing `PY`. It
writes only `tests/deployment/fixtures/noise_policy_parity.npz`. The generator
stays in this README and is not an importable module.

```python
from pathlib import Path
from types import SimpleNamespace

import numpy as np
import torch

from omg_posttrain.learning.noise_ppo.flow import FlowNoiseActor, FlowNoiseDecoder
from omg_posttrain.learning.noise_ppo.evaluation_sampling import PairedEvaluationSampling

torch.set_num_threads(1)
torch.backends.cuda.matmul.allow_tf32 = False
torch.backends.cudnn.allow_tf32 = False
actor = FlowNoiseActor().eval().requires_grad_(False)
with torch.no_grad():
    for index, (name, parameter) in enumerate(actor.named_parameters()):
        flat = torch.arange(parameter.numel(), dtype=torch.float64)
        values = 0.015 * torch.sin(flat * 0.013 + index) + 0.005 * torch.cos(flat * 0.007 + index)
        parameter.copy_((values - (0.2 if name == "log_std" else 0.0)).float().reshape(parameter.shape))

mean = torch.linspace(-0.2, 0.2, 38, dtype=torch.float32)
std = torch.linspace(0.5, 1.5, 38, dtype=torch.float32)
decoder = FlowNoiseDecoder(SimpleNamespace(
    reference=SimpleNamespace(mean=mean, std=std), committed_frames=25))
contexts = []
for rows in (10, 35):
    flat = np.arange(rows * 36, dtype=np.float32).reshape(rows, 36)
    q = (0.1 * np.sin(flat * 0.031)).astype(np.float32)
    angle = np.arange(rows, dtype=np.float32) * 0.017 + 0.2
    axis = np.asarray([0.3, -0.4, 0.5], dtype=np.float32)
    axis /= np.linalg.norm(axis)
    q[:, 3] = np.cos(angle / 2)
    q[:, 4:7] = np.sin(angle[:, None] / 2) * axis
    q[:, 0] += 1.2
    q[:, 1] -= 0.4
    q[:, 2] += 0.8
    contexts.append(q)

keys = np.asarray([[7, 3, 0], [7, 3, 1], [19, 8, 34]], dtype=np.int64)
observations, means, samples, edges, sums = [], [], [], [], []
with torch.inference_mode():
    for index, (seed, episode, request) in enumerate(keys):
        epsilon = PairedEvaluationSampling(seed, [episode]).epsilon(
            [episode], [request], action_dim=3800, device="cpu", dtype=torch.float32)
        edges.append(torch.cat([epsilon[0, :64], epsilon[0, -64:]]).numpy())
        sums.append(epsilon.double().sum().item())
        if index < len(contexts):
            observation = decoder.observation(contexts[index][None])
            distribution = actor.distribution(observation)
            observations.append(observation[0].numpy())
            means.append(distribution.mean[0].numpy())
            samples.append(distribution.sample(base_noise=epsilon)[0].reshape(100, 38).numpy())

np.savez_compressed(Path("tests/deployment/fixtures/noise_policy_parity.npz"),
    context10=contexts[0], context35=contexts[1], mean=mean.numpy(), std=std.numpy(),
    observations=np.stack(observations), actor_means=np.stack(means),
    samples=np.stack(samples), keys=keys, epsilon_edges=np.stack(edges),
    epsilon_sums=np.asarray(sums, dtype=np.float64))
```
